# Changelog

## Unreleased

### PantryCraft
- Added Room schema v1-to-v2 migration for storage location, category, expiration, opened-state, and notes fields.
- Added indexes for pantry location, expiration, and barcode lookup.
- Enabled Room write-ahead logging for concurrent UI and background access.
- Replaced manual repository refreshes with reactive Room `Flow` streams.
- Added migration instrumentation coverage that verifies existing pantry data survives the schema upgrade.
- Added a Gradle ktlint quality gate for Kotlin sources.
- Added Android KeyStore-derived SQLCipher encryption with WAL, busy timeout, and memory-mapped I/O settings.
- Added Pantry location filter chips and color-coded expiration status indicators.
- Added reactive DAO insert/update instrumentation coverage and location-filter unit tests.
- Added manual SQLite FTS5 indexing with synchronization triggers and prefix search over item names, notes, and categories.
- Added debounced pantry search UI and an Expiring Soon inventory filter.
- Added normalized names, unit metadata, purchase/created/updated timestamps, and migration backfill for legacy pantry rows.
- Added StrongBox-first SQLCipher key generation with TEE fallback and explicit invalidated-key failure handling.
- Added tombstone-based soft delete and restore support; default inventory flows and FTS searches exclude deleted records.
- Added deterministic clock injection to Expiring Soon filtering.
- Replaced deterministic HMAC database-key derivation with a random 256-bit SQLCipher passphrase wrapped by an Android KeyStore AES-256-GCM key.
- Added Snackbar undo for soft-deleted pantry items.
- Added Counter storage filtering to complete the four supported inventory locations.
- Added atomic quantity decrement with a zero floor and a "Use 1" inventory action.
- Disabled Android app backup to prevent encrypted database and key-wrapper state from being restored inconsistently.
- Replaced the initial navigation graph composition with lightweight state-based routing and back handling to reduce startup composition work.
- Moved dashboard, pantry, grocery, and backup navigation into a persistent Material 3 bottom navigation bar; removed dashboard navigation buttons.
- Added Phase 2 CameraX live analysis foundation with Camera permission handling, a lifecycle-bound preview, 15 FPS throttling, ML Kit barcode scanning, object detection, normalized bounding boxes, and guaranteed ImageProxy closure.
- Added the live camera preview surface and Compose bounding-box HUD overlay for detected objects.
- Added ephemeral high-resolution shelf capture: private JPEG scratch files are downscaled to WebP, returned as volatile bytes, and deleted immediately after capture processing.
- Added bounded snapshot decoding with bounds-first sampling, RGB_565 source buffers, strict normalized vision JSON parsing/repair, and a batch review composable.
- Added Room-backed custom barcode associations with 2.5-second scan debouncing and offline resolver contracts.
- Added an optional Open Food Facts SQLite catalog with 59,723 validated food barcode records; it is downloaded into app-private storage when requested and remains outside the APK and Git.
- Replaced the Backup navigation tab with Settings, grouping encrypted database backup and FoodFacts catalog download into separate cards.
- Added a local live-analysis timing readout for verifying ML Kit frame processing latency on-device.
- Moved the FoodFacts download card above backup settings and rewrote both cards with plain-language explanations.
- Removed bottom-navigation labels and enlarged the accessible navigation icons to use the available space.
- Enhanced Settings with a clear purpose statement, catalog readiness status, private-storage guidance, and full-width actions.
- Replaced text-symbol navigation buttons with modern Material icons, using outlined icons at rest and filled icons for the active destination.
- Replaced the pantry plus sign and empty grocery FAB icon with accessible Material icons.
- Replaced the scanner capture text button with an accessible camera FAB icon.
- Connected scanner review confirmation to encrypted pantry persistence, including shelf-life dates and item metadata.
- Added selective add/dismiss controls and quantity increment/decrement controls to scanner review.
- Updated scanner review quantities to hide unnecessary trailing zeroes while preserving meaningful decimals.
- Clarified scanner review metadata, renamed Dismiss to Remove, and added modal editing for item names and categories.
- Renamed the scanner review confirmation action from Add to Save.
- Added category and unit dropdowns to the scanner item editor; non-count units now use a decimal keypad quantity field.
- Applied integer increment/decrement controls to Count, Each, Package, Can, and Bottle units.
- Centralized pantry categories, units, and discrete-quantity unit definitions for consistent editing across the app.
- Centralized storage locations and added a storage-location dropdown to scanner item editing.
- Centralized shelf-life options and added shelf-life editing to scanner item review.
- Changed modal shelf-life editing to preset increment/decrement controls, with zero represented as None.
- Changed shelf-life controls to single-day integer increments/decrements with additional quick presets.
- Reused the scanner review sheet for pantry add and edit flows, including quantity, category, unit, storage, and shelf-life editing.

- Simplified the single-item review confirmation label to Save.

- Improved FoodFacts catalog downloads with byte progress, downloaded file size, retry-friendly success/failure dialogs, and confirmation-protected deletion.
